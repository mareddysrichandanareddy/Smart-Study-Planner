# Smart Study Planner

## Project Overview

Smart Study Planner is a Python-based GUI application developed using Tkinter. It helps students organize study schedules, manage study hours, and track learning progress efficiently.

## Features

* User-friendly GUI
* Study schedule generation
* Subject-wise planning
* Progress tracking
* Schedule storage
* Time management support

## Technologies Used

* Python
* Tkinter
* File Handling

## Project Structure

* main.py
* planner.py
* progress_tracker.py
* subjects.txt
* progress.txt
* requirements.txt

## Future Enhancements

* Exam Countdown Timer
* AI-based Subject Recommendation
* Attendance Tracking
* Performance Analytics Dashboard
* Cloud Data Storage

## Conclusion

The Smart Study Planner improves productivity and helps students manage their academic activities effectively.
